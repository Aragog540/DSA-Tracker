# 🎯 Rani & Swaroop DSA Tracker

A modern, light-themed DSA preparation sheet designed for **Rani & Swaroop** with dynamic target scheduling, adaptive buffer expansion, and a joint activity calendar.

## 🌟 Key Features

- **Warm Light Aesthetic**: Earthy color palette with terracotta orange, chocolate brown, warm rose, and cream.
- **Dual Partner Tracking**: Switch between **🦊 Swaroop** and **🌸 Rani** with dedicated checkboxes, stats, and progress bars.
- **Fixed Oct 15 Deadline**: Calibrated topic distribution based on hardness (Easy = 1 pt, Medium = 2.5 pts, Hard = 4.5 pts).
- **Adaptive Buffer Expansion**: Completing early topics automatically redistributes saved days to harder topics (DP, Trees, Graphs).
- **Joint Activity Calendar**: Visual heatmap and daily activity feed tagged by topic and partner.
- **🔄 Sync & Share**: One-click JSON progress export and merge across devices.
- **150+ Top LeetCode Problems**: Comprehensive coverage across 18 core DSA topics.
